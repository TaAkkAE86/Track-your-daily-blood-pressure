# บันทึกความดัน — สุขภาพทุกวัน

เว็บแอปภาษาไทยสำหรับบันทึกความดันโลหิตและชีพจรประจำวัน พร้อมประวัติ กราฟแนวโน้ม และคำแนะนำเบื้องต้น

## ใช้งาน

- เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ (เช่น GitHub Pages) เพื่อใช้งานบนมือถือและคอมพิวเตอร์
- ติดตั้งเป็นแอปได้จากปุ่ม **ติดตั้งแอป** ในเบราว์เซอร์ที่รองรับ หรือใช้เมนู **Add to Home Screen / เพิ่มไปยังหน้าจอโฮม**
- บันทึกจะใช้วันและเวลาประเทศไทย (Asia/Bangkok, UTC+07:00) ณ เวลาที่กดบันทึก
- ประวัติเก็บใน local storage ของเบราว์เซอร์บนอุปกรณ์นี้ ไม่มีการส่งข้อมูลไปเซิร์ฟเวอร์
- ส่งออกประวัติเป็น CSV ได้จากปุ่ม **ส่งออก CSV**

## ข้อควรทราบ

เกณฑ์ในแอปเป็นคำแนะนำทั่วไปสำหรับผู้ใหญ่และไม่ใช่การวินิจฉัยโรค ค่าความดันและชีพจรต้องพิจารณาร่วมกับอาการ ยา โรคประจำตัว และคำแนะนำจากบุคลากรทางการแพทย์ หากความดันตั้งแต่ 180/120 mmHg ขึ้นไป ให้วัดซ้ำหลังพัก 5 นาทีและติดต่อสถานพยาบาล; หากมีอาการฉุกเฉิน เช่น เจ็บหน้าอก หายใจลำบาก อ่อนแรง/ชาครึ่งซีก หรือสับสน โทร 1669
