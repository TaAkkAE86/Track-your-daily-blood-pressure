# บันทึกความดัน — สุขภาพทุกวัน

เว็บแอปภาษาไทยสำหรับบันทึกความดันโลหิตและชีพจรประจำวัน พร้อมประวัติ กราฟแนวโน้ม คำแนะนำวิธีวัด และสำรองข้อมูล

## คุณสมบัติ

- บันทึกความดันตัวบน ตัวล่าง ชีพจร อาการ และช่วงเช้า/เย็น
- แสดงเวลาอัตโนมัติตามประเทศไทย (Asia/Bangkok, UTC+07:00)
- แสดงค่าที่บันทึกล่าสุด ค่าตอนเช้า/เย็น และค่าเฉลี่ย 7 วัน
- แสดงแนวโน้มจากผลล่าสุด พร้อมแก้ไขหรือลบรายการ
- ส่งออกประวัติเป็น CSV และนำเข้าข้อมูลสำรองจากไฟล์ JSON
- ใช้ได้แบบ PWA และบันทึกข้อมูลในอุปกรณ์ผ่าน local storage

## วิธีวัดที่ถูกต้อง

1. งดชา กาแฟ แอลกอฮอล์ บุหรี่ และออกกำลังกายอย่างน้อย 30 นาที
2. ถ่ายปัสสาวะพักนั่งหลังพิงพนักนิ่ง ๆ 5 นาที โดยวางเท้าบนพื้น
3. วางแขนที่ระดับหัวใจ ใช้ปลอกแขนขนาดพอดี วัดต้นแขนหากทำได้
4. ไม่พูดคุยหรือขยับขณะวัด วัดซ้ำ 2 ครั้งห่างกัน 1–2 นาที
5. บันทึกค่าเฉลี่ยของรอบที่วัด และวัดในเวลาใกล้เคียงกันทุกวัน

## ขอบเขต

เกณฑ์สำหรับผู้ใหญ่ทั่วไปและไม่ใช้วินิจฉัยโรค ค่าผิดปกติควรยืนยันจากหลายครั้งและแพทย์ เด็ก การตั้งครรภ์ และผู้ป่วยโรคประจำตัวอาจต้องใช้แนวทางเฉพาะ
